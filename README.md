# journal-to-screen

A proof of concept for a Web Push notification relay: a photo uploaded from one
phone produces a generic notification on a parent's iPhone Home Screen app, and
tapping it opens the photo behind a login.

This repository starts as a placeholder. The proof-of-concept code arrives in a
pull request. It contains no AI, no journal reading or grading, no reward
ledger and no Family Link or Google-account integration.
